# Python Practice Project

A simple Python project to practice type hints, virtual environments, and pytest.

## Features

- Calculator with basic operations
- Utility functions (is_even, reverse_string, etc.)
- Full pytest coverage (22 tests)
- Type hints everywhere

## Project Structure

- calculator.py - Basic math functions
- utils.py - Utility functions
- tests/ - Test files
- requirements.txt - Dependencies
- conftest.py - pytest configuration

## Installation

1. Clone the repo
2. Create venv: python3 -m venv .venv
3. Activate: source .venv/bin/activate
4. Install: pip install -r requirements.txt

## Running Tests

Run: pytest -v

Should show: 22 passed

- Python 3.10
